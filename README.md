# Netatmo Interview

This project is a small C++ implementation of the Netatmo technical interview challenge. It focuses on a cellular automata simulation inspired by Conway's Game of Life, with a few design choices and optimizations discussed in the statement.

## Build

```bash
g++ -Wall -Wextra -std=c++23 *.cpp -o technical_test
```

## Run

```bash
./technical_test
```
